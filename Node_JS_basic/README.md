## Description
The goal of this project is to introduce the basics of Node.js, including its core modules, asynchronous programming, and how to build simple back-end applications. The exercises are designed to provide hands-on experience with Node.js.

## Learning Objectives
By completing this project, you will learn:
- The basics of Node.js and its runtime environment.
- How to use Node.js modules (e.g., `fs`, `http`, `path`).
- The principles of asynchronous programming in Node.js.
- How to create a simple server using Node.js.
- Debugging and error handling in Node.js applications.

## Installation
To get started, clone this repository and install the necessary dependencies:
```bash
git clone https://github.com/your-username/Node_JS_basic.git
cd Node_JS_basic
npm install
```

## Usage
Run the exercises or scripts using Node.js:
```bash
node <script_name>.js
```
